# Maxupport 小說訂閱測試邀請草稿

最近想請朋友們幫我一個忙。

我把兩本寫完的小說，整理進自己的網站了。

一本是《她沒有說好的那一夜》，一本是《越界之前》。寫的是關係裡那些不太好回答的問題：靠近一個人之前，我們到底知道多少？有些話沒有說出口，是因為還沒準備好，還是其實已經做了選擇？

平常做生涯擺渡，比較常陪人整理正在發生的事。這次換個方式，把一些想繼續追問的問題，放進故事裡。

現在兩本都可以先讀第一章，不用登入，也不用付費。讀完有興趣，再留下信箱，之後有新章節就會收到通知。

不過，在正式邀更多人進來之前，想先請熟面孔幫忙走一遍：

試著訂閱看看，有沒有收到歡迎信？用手機讀小說順不順？哪個按鈕讓你找不到，或哪一句說明看不懂，也請直接跟我說。

不用特別客氣，這一輪就是來找問題的 😅

當然，如果你願意多告訴我一句「讀完第一章，你想不想繼續看」，那對我會很有幫助。

試讀與訂閱在這裡：
https://museum-of-max.vercel.app/novels

不想再收信，信裡也有取消訂閱的連結。

謝謝願意先上船，陪我試試這條新航線的朋友。

Max｜生涯擺渡人
